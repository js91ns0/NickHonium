# NickHonium — поиск профилей по нику в социальных сетях и на форумах

NickHonium — это инструмент командной строки для поиска учётных записей пользователя по его нику на сотнях сайтов: соцсети, форумы, IT-площадки, блоги и доски объявлений. Всё — через открытые источники, без взлома и API.

Возможности
- Проверка наличия профиля на **310+** сайтах (из файла `sites.txt`).
- Работа с **любыми** сайтами — вы сами добавляете новые площадки в файл списка.
- **Многопоточный** поиск — быстро проверяет все сайты параллельно.
- **Цветной** вывод в консоль (found / not found / login required / error).
- Сохранение результатов в **JSON** для дальнейшего анализа.
- **Интерактивный режим** (можно вводить ники один за другим).
